# 자동 동시 요청 검증

자동 비교는 과목과 입출력 길이 분위수를 반영한 동일 문항을 사용합니다. 준비 실행을 제외하고 각 설정을 3회 측정하며, 기존 동시 수와 상한 내 1·2·4·8 후보를 비교합니다. 중간 후보가 느려도 높은 후보를 생략하지 않습니다.

API 요청 시작부터 종료까지의 시간 합집합으로 모델 처리량을 계산하고, 저장·채점·스케줄 대기는 별도 기록합니다. 기존 설정보다 처리량과 요청 완료시간이 모두 10% 이상 개선되고, 반복별 정답 품질이 낮아지지 않은 후보만 채택합니다. 실제 라운드 전체 시간이 5% 넘게 악화되는 후보도 거부합니다. 10분 안에 근거가 완결되지 않으면 기존 설정을 유지합니다. 새 시험의 기본값은 단일 요청입니다.

기존 본시험 이력이 있는 자동 변경은 이후 실제 처리량도 확인합니다. 같은 과목·데이터셋 및 비슷한 입출력 길이의 정상 응답을 비교합니다. 32문항·30초 이상인 구간에서 50% 이상 하락하거나, 별도 두 구간에서 각각 20% 이상 하락하면 진행 중인 응답을 끝낸 뒤 이전 설정으로 복구합니다. 자동 변경을 해제하고 복구 이유와 측정값을 기록하며, 실패한 선택의 동시 처리 가산점은 제거합니다.

수동으로 정한 동시 수는 바꾸지 않습니다. 새 시험처럼 기준 이력이 없거나, 과목·길이가 바뀌거나, 계측 누락·출력 잘림·긴 중지 때문에 비교가 불가능하면 처리량 회귀로 단정하지 않습니다. 이 보호는 모든 서버 장애나 처리량 저하를 탐지하는 기능은 아닙니다.

기존 원문·usage·문항 순서는 유지됩니다. 이전 방식(v1)의 미완료 자동 비교는 재개할 때 현재 설정을 유지하며 종료합니다. 새 비교는 명시적인 재측정으로 시작합니다.

## 임시 과목별 제한

일시정지 상태에서 `POST /api/runs/{id}/subject-limit`에 `{ "limit": 1000 }`을 전달하면 해당 시험만 과목별 최대 1,000문항으로 제한합니다. 이미 완료·실행 중인 문항은 합산하며, 이미 상한을 넘겼다면 기존 답변을 보존하고 추가 문항을 배정하지 않습니다. 제외된 원본문항은 삭제하지 않습니다. `limit: null`은 제한 해제입니다. 전체 문항 중 일부만 실행한 결과이므로 전체 평가팩 완료와 구분해야 합니다.
