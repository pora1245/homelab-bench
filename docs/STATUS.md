# 구현 상태 · 2026-11-07

LLM Bench는 로컬에서 모델 API에 문제를 전달하고 답안 채점, 응답 성능 측정, 실행 장비 모니터링과 보고서 저장을 제공하는 비공개 베타입니다. 시험 기록과 결과의 개발자 서버 자동 업로드는 없습니다. 외부 모델·채점 API로 보내는 데이터는 사용자가 선택한 연결에 따라 전송됩니다.

## 사용할 수 있는 기능

- AI 설치 안내에 따른 질문·선택 구성 저장·설치 및 연결 확인
- 별도 초기 준비 화면 없이 홈 진입, 연결 관리에서 설정·추가·상태 확인
- 모델·채점 API와 실행 장비 연결을 한 번 저장하여 재사용
- 같은 PC, 다른 PC·서버, 클라우드 API의 실행 위치 구분
- 빠른 시험·전체 시험과 과목 선택, 실시간 답변·판정·진행 상태
- 지능·성능·종합 점수 자동 표시와 미측정 영역의 범위 표시
- 품질 문제를 푸는 동안 수집한 단일 TTFT·Decode 기본점수와 검증된 동시 처리 가산
- 대표 길이 문항의 단일·기존·후보 동시 수를 3회 비교해 자동 선택, 근거 부족 시 기존 설정 유지 및 본시험 회귀 시 복구
- 시험별 동시 실행과 일시정지·재개, 실제 풀이·채점 시간 기반 완료 예상
- FHD 시험 현황: 지표·문항별 판정과 문제·답안 비교를 한 화면에 배치
- 지능·성능·종합·문항별 보고서와 세 가지 테마, PNG·SVG·HTML·PDF 저장
- 시험 기록 휴지통·복원, 저장 답안 재채점과 판정 이력 보존
- 인증된 독립 Rust 장비 수집기, Linux SSH와 로컬 수집
- 선택 설치하는 Docker 코드 채점 환경

## 확인한 환경

Apple Silicon Mac의 실행 번들과 Windows PC의 빌드된 앱에서 실제 시험을 수행했습니다. Windows는 개별 PC 실행 검증과 범용 설치 패키지 검증을 구분합니다. 테스트는 임시 DB·모의 API를 사용하며 실제 모델 호출 없이 실행할 수 있습니다.

성능 자동 판정 수정 시 Rust 35개, API 통합 79개, 자동 이관 42개, 휴지통 23개, 프론티어 점수 15개 검사가 통과했습니다. 테스트 수는 후속 수정에 따라 달라질 수 있습니다.

## 후속 작업

- 일반 사용자가 내려받는 Windows 실행 ZIP의 대상별 의존성·라이선스·새 환경 검증
- Linux·Intel Mac의 전체 앱 새 설치 검증
- macOS 서명·공증 및 배포 절차
- Windows AppContainer·Mac App Sandbox 기반 코드 채점의 공식 채점기 호환성·자원 제한 검증
- 모델 문맥·출력 한도의 사전 확인 강화
- 사용자가 선택하는 결과 공유 서비스

LiveCodeBench 원문·테스트는 기본 저장소에 넣지 않으며 별도 설치 절차를 사용합니다. 앱 고유 코드의 공개 라이선스와 공개 배포는 아직 정하지 않았습니다.
