# 구현 상태 · 2026-11-09

LLM Bench는 로컬에서 모델 API에 문제를 전달하고 답안 채점, 응답 성능 측정, 실행 장비 모니터링과 보고서 저장을 제공하는 비공개 베타입니다. 시험 기록과 결과의 개발자 서버 자동 업로드는 없습니다. 외부 모델·채점 API로 보내는 데이터는 사용자가 선택한 연결에 따라 전송됩니다.

## 사용할 수 있는 기능

- AI 설치 안내에 따른 질문·선택 구성 저장·설치 및 연결 확인
- 별도 초기 준비 화면 없이 홈 진입, 연결 관리에서 설정·추가·상태 확인
- 모델·채점 API와 실행 장비 연결을 한 번 저장하여 재사용
- 같은 PC, 다른 PC·서버, 클라우드 API의 실행 위치 구분
- 기본 벤치팩 하나의10분·1시간·4시간·8시간 모드와 과목 선택, 실시간 답변·판정·진행 상태
- 지능·성능·종합 점수 자동 표시와 미측정 영역의 범위 표시
- 품질 문제를 푸는 동안 수집한 단일 TTFT·Decode 기본점수와 검증된 동시 처리 가산
- 대표 길이 문항의 단일·기존·후보 동시 수를 3회 비교해 자동 선택, 근거 부족 시 기존 설정 유지 및 본시험 회귀 시 복구
- 시험별 동시 실행과 일시정지·재개, 실제 풀이·채점 시간 기반 완료 예상
- FHD 시험 현황: 지표·문항별 판정과 문제·답안 비교를 한 화면에 배치
- 지능·성능·종합·문항별 보고서와 세 가지 테마, PNG·SVG·HTML·PDF 저장
- 시험 기록 휴지통·복원, 저장 답안 재채점과 판정 이력 보존
- 인증된 독립 Rust 장비 수집기, Linux SSH와 로컬 수집
- 선택 설치하는 Docker 코드 채점 환경

## 기본 벤치팩 시간 보정

버전 `2026-11-09.1`의41·160·536·1,010문항 구성을 확정했습니다. Qwen3.8 Flash IQ3·RTX3060·단일 요청·기본 추론(xhigh)에서 실제 요청 시간은10분22.5초·1시간1분5.5초·4시간16분14.4초·8시간8분56.8초로 모두±20% 기준을 통과했습니다. 10분은3회 중앙값이며 범위는9분21.9초~11분32.4초, 나머지는 단독1회입니다.

4시간과8시간 원본의 출력 실패2건·4건은 원점수와 함께 보존했습니다. 전체 요청 계측은 완료됐지만 출력 완결성은 통과하지 못했으며, 같은 설정의1회 진단을 첫 회차 시간과 섞지 않았습니다. [기본팩 설명](BASIC-PACK.md)에 구성·시간 근거·실패·미검증 범위를 기록했습니다. 실행 번들 검증은 시간 보정과 별도입니다.

## 확인한 환경

Apple Silicon Mac 실행·소스 ZIP의 파일 감사와 Mac 실행 번들의 빈 DB·독립 포트 실행을 확인했습니다. 실제 앱 API로 네 모드의 구성과 GSM8K 문항 수 4·18·37·62개 및 실행 순서를 확인했습니다. Windows x86_64 실행 ZIP도 기존 Windows PC의 별도 추출 폴더·빈 데이터에서 루트 시작기로 실행해 상태 응답·웹 UI·네 모드 구성과 종료를 확인했습니다. 이 배포 검증의 모델 API 호출은 0건입니다. 앞서 수행한 실제 모델 시간 보정과 배포 시작 검증을 구분합니다.

Windows 실행 파일의 DLL 의존성은 Windows 시스템 DLL로 한정됐으며, 대상 Rust 의존성 고지 193개와 빌더 고지 원문 23개를 포함했습니다. 이는 앱 실행 파일에 대한 확인이며, 일반·코드 채점 환경은 사용자가 선택한 준비 절차를 따릅니다. 별도 새 OS와 일반 채점 의존성의 신규 설치까지 검증한 것은 아닙니다.

성능 자동 판정 수정 시 Rust 35개, API 통합 79개, 자동 이관 42개, 휴지통 23개, 프론티어 점수 15개 검사가 통과했습니다. 테스트 수는 후속 수정에 따라 달라질 수 있습니다.
