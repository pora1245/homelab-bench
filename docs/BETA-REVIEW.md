## 기본 평가 범위

신규 종합 시험은 GSM8K·MATH-500·MMLU-Pro·IFEval·HumanEval·MBPP·BIG-Bench Hard의 7개 공개 품질팩, 전체 21,567개/빠른 354개다. 성능은 해당 문제 풀이에서 수집한다. API Experience 13개는 신규 선택·종합 구성에서 제외하고 기존 기록과 API 호환용 자료로 보관한다. 2026-11-06 검증 당시의 21,580개/빠른 367개 기록은 그대로 유지한다.

## 공유 범위와 후속

현재는 Apple Silicon Mac 테스터용 실행 ZIP·소스 ZIP이다. 실제 검증은 같은 Mac에서 새 폴더·빈 DB·빈 연결·별도 포트로 수행했다. 별도 물리 Mac/새 OS·Intel Mac·Linux·Windows와 서명·공증은 후속이다. Python 전이 의존성은 완전한 플랫폼별 lock이 아니며 설치 시 인터넷이 필요하다.

입력 문맥/출력 한도 사전 검사, 정제된 API 오류 원인 및 반복 설정 오류 중단 정책, 실제 동시 요청·채점 API 검증이 남아 있다. 온라인 결과 게시·계정·동의·공유 취소·위변조 검증은 다음 별도 단계다. 앱 자체 공개 OSS 라이선스를 임의 지정하지 않았으며, 제3자 고지와 공유 범위는 시작 안내를 따른다.

보안 검토는 확인한 경로에 대한 코드·계약 검사다. 모든 공격에 안전하다는 인증이나 외부 침투 시험 완료를 뜻하지 않는다.
