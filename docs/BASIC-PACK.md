# 기본 벤치팩

평가팩 목록에서 **기본 벤치팩** 하나를 선택한 뒤 **10분·1시간·4시간·8시간** 중 시험 시간을 고릅니다. 수학·지식·복합 논리·지시 이행·코딩을 포함하며 원본 출처와 채점 방식은 그대로 유지합니다.

Qwen3.8 Flash IQ3, RTX 3060, 단일 요청, 엔진 기본 추론(xhigh)으로 네 모드의 시간 보정을 마쳤습니다. 단일 약60 tok/s를 기준으로 구성했고, 네 모드 모두 승인된 **±20%** 범위에 들었습니다. 이 범위는 기준 구성의 보정 기준이며, 다른 모델의 완료 시간을 보장하지 않습니다.

재현 설정은 Temperature **0**, 요청 출력 상한 **8,192토큰**, 동시 요청 **1**, 요청 제한 시간 **600초**입니다. API의 추론 등급 필드는 비워 엔진 기본 xhigh를 사용했으며 각 문항의 고정 출력 한도도 함께 적용합니다.

## 확정 구성과 실측

| 시험 모드 | 문항 수 | 첫 회차 요청 시간 | 목표 대비 | 전체 회차 수 | 원본 출력 실패 |
|---|---:|---:|---:|---:|---:|
| 10분 |41|중앙10분22.5초|+3.75%|3회|0|
| 1시간 |160|1시간1분5.5초|+1.82%|1회|0|
| 4시간 |536|4시간16분14.4초|+6.77%|1회|2|
| 8시간 |1,010|8시간8분56.8초|+1.86%|1회|4|

10분 모드의 실제 범위는 **9분21.9초~11분32.4초**입니다. 나머지는 전체 회차를 한 번씩 측정했으므로 반복 실행의 변동 범위는 아직 확보하지 않았습니다. 모든 선택 문항의 요청 시간은 측정됐으며, 최종 시간에 미측정 문항의 추정 비용을 섞지 않았습니다.

시간은 추론과 답변 생성을 포함한 **첫 회차 전체 요청 시간의 합**입니다. 채점·채점 큐 대기와 진단 재시험 시간은 제외합니다. 단일 60 tok/s는 참고 기준이고 실제 보정에는 관측된 속도와 풀이 길이를 사용했습니다. 모델·추론·동시 요청 설정에 따라 실제 시간은 달라집니다.

## 출력 실패와 진단 결과

시간 보정 통과와 정상 출력 검증은 구분합니다. 요청·채점환경 오류와 계측 누락은 없었지만, 4시간 모드에는 출력 상한1건·반복 생성 종료1건, 8시간 모드에는 출력 상한2건·반복 생성 종료2건이 있었습니다. 이 문항의 원래 답변·점수·실패 시간도 그대로 보존했습니다.

각 실패 문항을 같은 설정으로 한 번만 다시 확인했습니다. 4시간 모드는98.8초의 추가 진단 후 `HumanEval/146`이, 8시간 모드는273.9초의 추가 진단 후 `HumanEval/146`과 `HumanEval/99`가 미해결로 남았습니다. 재시험 답변으로 원점수나 첫 회차 시간을 바꾸지 않았습니다. 따라서 긴 두 모드는 시간 보정은 통과했지만 `output_integrity_passed`와 `full_replay_verified`는 `false`입니다. 시간 계측이 완전한 출력 실패는 전체 소요시간에 포함되며, 정상 성능 표본이나 성공한 출력으로 바꾸어 표시하지 않습니다.

## 평가 범위

10분은 기본 확인용으로 원본 벤치7종을 각각 최소3문항 포함합니다. 1시간은 주요 능력 비교, 4시간과 8시간은 상세 검토용입니다. 하위 모드의 모든 문항은 상위 모드에 포함되며, 각 모드의 문항 순서는 manifest에 고정합니다.

| 원본 벤치 | 10분 | 1시간 | 4시간 | 8시간 |
|---|---:|---:|---:|---:|
| GSM8K |4|18|37|62|
| MATH-500 |15|46|130|254|
| MMLU-Pro |6|24|102|190|
| BIG-Bench Hard |3|23|101|203|
| IFEval |4|23|76|127|
| HumanEval |5|16|50|99|
| MBPP |4|10|40|75|
| 합계 |41|160|536|1,010|

8시간 모드는 MATH의35개 분야·난도 조합, MMLU-Pro14개 분야, BBH27개 유형과 IFEval24개 지시 ID를 포함합니다. GSM8K·코딩의 세부 의미 유형 전수 수작업 분류와 모든 포함 문항의 정답·오답 예제 전수 실행은 미완료입니다. 구조적 분류·채점기 검증·저장 답변 감사와 실제 시험으로 확인한 범위를 구분합니다. 이 발췌판의 점수를 원본 전 문항 점수와 동일하게 해석하지 않습니다.

## 버전과 사용 방법

팩 ID는 `basic-bench-v2`, 버전은 **`2026-11-09.1`**입니다. 하나의 `datasets/basic-pack/manifest-v2.json`에 네 모드의 문항 목록·순서·출처 해시·실측·실패·진단 근거를 저장합니다. 원본7종 데이터 파일은 보관하고 새 시험 선택 목록에서는 기본 벤치팩 하나로 표시합니다. 다른 사용자팩을 추가하는 기능은 유지합니다. 이전 시간팩과 시험 기록은 당시 이름·버전·문항으로 열 수 있습니다.

API 사용 시 `pack_id: "basic-bench-v2"`, `profile: "10m" | "1h" | "4h" | "8h"`를 지정합니다. 선택한 모드 전체 문항을 사용하며 원본의 빠른 표본 옵션을 다시 적용하지 않습니다. 과목을 일부 제외하면 해당 모드보다 문항 수와 시간이 줄어듭니다.

실행 번들의 운영체제별 검증 범위는 해당 배포 안내를 확인하세요. 시간 보정 완료가 모든 운영체제의 설치 검증 완료를 뜻하지는 않습니다.
