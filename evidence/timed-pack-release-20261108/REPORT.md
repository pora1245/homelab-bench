# 시간팩 v1 구현·검증 보고서

기존 공개 벤치 7종에서 10분 54개, 1시간 259개, 4시간 995개, 8시간 1,959개를 고정했다. PC와 Mac에 적용했으며 기존 시험 답변·원문·계측·설정을 보존했다. 새로운 진단 결과를 기다리지 않고 독립적인 제품·배포 작업을 진행했다.

추론 포함 생성량을 단일 60 tok/s로 환산하고 생성90%·비생성10% 예산을 적용했다. 채점 큐는 모델 비용에서 제외했다. 양쪽 정상 자료가 있는 문항은 큰 생성량을 사용했다. 8시간 중 579개만 양쪽 비용이 있고 1,380개는 DeepSeek 비용이어서 모든 모델에서 8시간을 보장하지 않는다.

입력·정답·원본 채점 조건·ID는 유지하고 출처 SHA256과 팩 버전을 고정했다. 하위 팩은 모두 상위 팩에 포함된다. 원본 파일이 바뀌면 해시 검증이 실패하므로 다른 문제로 조용히 대체하지 않는다. 출력 잘림448개·추출 미확정373개·원자료 결함5개는 보류/제외했다. 정상 오답과 긴 정상 답변은 유지했다.

8시간 팩은 BBH27유형·MMLU14분야·MATH35분야/난도 조합을 포함한다. 긴 풀이 구간483개와 정상 오답484개를 포함한다. GSM8K·코딩의 세부 의미 분류는 확정하지 못해 출처·풀이량·정오답을 대용 분류로 사용했다. 문제 의미를 전수 수작업으로 검토했다고 주장하지 않는다.

## 저장 답변으로 본 선정 영향

정오답·길이 구간을 층화해 반복을 줄였으므로 원본 점수를 추정하는 무작위 표본이 아니다. 특히 MMLU의 낮은 점수는 모델이 새로 나빠졌다는 뜻이 아니다. 같은 팩·버전끼리 비교해야 한다. 두 모델의 오답 차이는 후보 근거이며, 일반적 분별력이나 통계적 신뢰도 검증 완료를 의미하지 않는다.

별도 seed 두 개에서 8시간 문항 수는1,942·1,878개였다. MMLU 정확도49.91~55.05%, 최대차5.14%p였다. 이 결과를 보고 출시 seed나 문제를 점수에 맞게 바꾸지 않았다. 전체 근거는 `selection-validation.json`.

## 제품 변경

- 새 시험의 기본 팩은10분. 네 시간팩을 먼저 보여주고 원본 전 문항은 별도 유지한다.
- 시간팩을 다시 빠른 표본으로 축소하지 않고 고정 목록 전체를 실행한다.
- 각 과목 공식/적용 채점기의 준비 상태를 확인하고 코드 채점 미설치 범위를 표시한다.
- 보고서에 시간팩 이름·버전·발췌 범위를 남긴다. BBH는 기존 정책대로 별도 정확도이며 점수 가중치는 변경하지 않았다.
- 보고서 참고문구의 조건식 우선순위 오류를 함께 수정했다.

## 검증

Rust86개 통과·0실패·실제 자료용 감사1개 기본제외. 그 감사는 이전 BBH6,511개 전수 검증에서205개 정정·정답 회귀0을 확인했다. TS/Vite 빌드, 기존 점수27·성능24·답안81·처리량15개 계약 검증 통과. 네 팩 중첩·중복없음·7종 포함·예산·원본 변조 거부를 확인했다.

Mac 기존6시험220저장행과 Windows 기존3시험을 보존했다. Windows 전체 DeepSeek21,580완료, 전체 Qwen3,599완료/17,981대기, 후보102완료/101대기를 유지했다. 후보 시험만 제품 검증 동안 일시정지했다.

실제 Windows10분54문항 시험에서 사전검증·GPU 수집기 연결·API 계측을 확인했다. UI로 일시정지→실행중 응답 완료→새로고침→같은 시험 재개를 검증했다. 기존11개 완료 답변 해시, 전체54개 순서와 suite hash가 같았다. 근거 `pause-resume.json`. 최종 완료·보고서 저장 결과는 아래에 추가한다.

Mac의 현재 Docker는 저장소 오류로 코드 채점 준비에 실패했다. Mac에서 실제 코드 채점까지 성공했다고 표시하지 않으며, Windows의 정상 채점 환경으로 제품 경로를 검증한다. 모든 포함 문항의 정답·오답 예제를 각각 새로 실행한 것은 아니다. 공식/적용 채점기의 계약검사·저장답변 감사·제품54개를 검증 범위로 한다.

## 배포 범위와 남은 진단

한국어 사용법·출처고지·원본 데이터·고정 manifest·앱을 번들에 포함한다. 원시 응답·장비 이력·API 키는 제외한다. 개인 비공개 GitHub에 코드와 안전한 문서만 반영한다. 앱 자체의 외부 재배포 라이선스는 미정이며 임의로 새 라이선스를 부여하지 않는다.

DeepSeek length448개 한도확대 시험은13+435개로 준비했다. 모델은 내려가 있고 하네스 작업 잠금이 갱신 중이므로 강제로 적재하지 않았다. 이 진단은 시간팩의 고정·앱 구현·배포를 막는 선행 조건에서 분리했다. 새 결과는 다음 팩 버전 검토 자료로 보존한다.

## 배포 검증 결과

`data/releases/timed-v1-20261108-verified/`에 Mac 실행 번들과 소스 번들을 만들었다. 빈 데이터 디렉터리에 새로 풀어 health·4개팩의 정확한 수량·UI·채점기 미설치 안내를 검증했다. 사용자 시험0·연결0, 개인정보 검사 통과, 파일 해시 일치, Rust184개·npm22개 의존 고지 누락0. 자세한 해시는 `release-report.json`, 격리 기동 근거는 `clean-smoke.json`.

Windows는 기존 설치의 실행 파일과 UI를 갱신해 실사용 검증했다. Windows용 독립 실행 ZIP은 이번 묶음에 없고, 소스 번들에는 Windows 설치·시작 스크립트가 포함된다. 긴1/4/8시간팩을 실제로 모두 끝까지 실행한 검증은 하지 않았다. 동일 실행기·목록 무결성·복구경로와54문항 제품 시험을 검증 범위로 한다.

## 실제54문항 완료·저장 결과

Windows에서54/54문항 완료, 요청오류0·채점실패0·출력잘림0. GSM8K5·MATH6·MMLU10·BBH16·IFEval5·HumanEval4·MBPP8개의 채점기 버전을 저장했다. TTFT·Decode·Prefill 계측 누락0이며 실제 GPU 사용률·온도·전력 이력도 수집했다.

실제 진행 시간은20.27분(일시정지 제외), 총 생성67,420토큰으로 단일60 tok/s 환산18.73분이다. 선정 기준32,111토큰 대비2.10배였다. 10분은 기준 모델의 비용을 사용한 팩 이름이며, 이번 Qwen에서는10분을 충족하지 못했다. 모델별 추론량 차이와 미측정 비용 때문에1/4/8시간도 실시간 상한이라고 주장할 수 없다. 다음 비용 보정의 근거로 원문·계측을 저장했으며 점수에 맞춰 같은 버전의 문항을 교체하지 않았다.

종합 보고서 PNG 저장 버튼을 눌러 실제2240×1680파일을 생성했고 육안 확인했다. 라이트·다크·인쇄용 테마 전환도 확인했다. `product-report.png`, `product-complete-screen.png`, `product-quick.json`이 근거다. 화면 점수는 기존 정책의 종합72.9/지능81.8/성능558.1이며 별도 성능시험을 실행하지 않았다. 이 점수는 범용 모델 순위나 원본 전체 점수로 해석하지 않는다.

제품 시험 완료 후 후보203문항 시험을102개 완료 지점에서 재개했다. 기존 전체 Qwen은 중복 작업을 피하려고 보존·일시정지 상태를 유지한다. DeepSeek 한도확대 진단은 활성 하네스 잠금으로 대기한다.
